# Brand assets

Placeholders. Paths and dimensions are declared in `config/brand.ts`; replace the
files here and update that file if the dimensions change.

| File | Purpose | Required size |
|---|---|---|
| `logo.svg` | Full lockup, header and footer | any, declare in config |
| `mark.svg` | Mark only, favicon source | square |
| `og-default.png` | Fallback social share image | exactly 1200x630 |

`og-default.png` must be 1200x630 or it renders cropped on X and Facebook.
